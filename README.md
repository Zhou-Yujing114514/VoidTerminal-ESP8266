# VoidTerminal-ESP8266

跑在 ESP8266（ESP-12F）墨水屏上的设备固件：虚空终端聊天、AP/Web 配网。

> v2.5.0：已移除服务器监控与时钟功能，主菜单改为双卡片布局并显示版本/WiFi 状态。

## 安全说明（审计修复）

本仓库源码中**不再包含任何硬编码口令或生产服务器基础设施信息**。以下项均改为运行时配置或首启随机生成：

- **AP 热点口令 / Web 配网 / OTA 口令**：首次上电时由设备用芯片 ID + 硬件随机数生成 16 位口令，存入 EEPROM，并在墨水屏配网界面上显示。源码中无任何默认口令。
- **聊天服务器**：`buer.kdns.fr` 为非敏感公开域名（走 Cloudflare + WSS + 证书指纹 pinning），聊天账号/密码仍由配网页写入 EEPROM。

## 构建与发布

- PlatformIO，board = `nodemcuv2`。
- 固件二进制（`.bin`）**不入库**，通过 GitHub Actions 构建后以 Release 附件分发。
