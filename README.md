# VoidTerminal-ESP8266

跑在 ESP8266（ESP-12F）墨水屏上的设备固件：虚空终端聊天、服务器监控、时钟、AP/Web 配网。

## 安全说明（审计修复）

本仓库源码中**不再包含任何硬编码口令或生产服务器基础设施信息**。以下项均改为运行时配置或首启随机生成：

- **AP 热点口令 / Web 配网 / OTA 口令**：首次上电时由设备用芯片 ID + 硬件随机数生成 16 位口令，存入 EEPROM，并在墨水屏配网界面上显示。源码中无任何默认口令。
- **监控服务器地址/端口**：出厂默认为空（监控功能默认关闭）。在配网网页（`http://192.168.4.1`）的「服务器监控配置」中填写主机与端口，存入 EEPROM；主机留空即关闭对应监控项。
- **聊天服务器**：`buer.kdns.fr` 为非敏感公开域名（走 Cloudflare + WSS + 证书指纹 pinning），聊天账号/密码仍由配网页写入 EEPROM。

### 监控通道安全（L19）

监控探针 `/api/status` 仅返回在线状态/延迟等公开指标，不含账号或 token；固件按明文 `http://host:port/api/status` 拼接 URL。**请勿把监控端点直接暴露公网**——应仅在内网或加密隧道（WireGuard / frp TLS 等）中使用。聊天主通道走 WSS(443) + 证书指纹 pinning，不受影响。

## 构建与发布

- PlatformIO，board = `nodemcuv2`。
- 固件二进制（`.bin`）**不入库**，通过 GitHub Actions 构建后以 Release 附件分发。
